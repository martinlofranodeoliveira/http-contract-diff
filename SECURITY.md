# Segurança

O programa lê contratos locais e não realiza chamadas HTTP. A análise não valida segurança, autorização ou comportamento da aplicação descrita. O perfil deliberadamente rejeita construções não suportadas.

Relatórios contêm caminhos de operações e nomes de campos. Valores de enum são omitidos, mas isso não torna o resultado uma anonimização completa. Revise o conteúdo antes de compartilhar.

Para relatar um possível problema, utilize o recurso privado **Report a vulnerability** do GitHub quando estiver disponível. Se não estiver disponível, abra apenas uma issue solicitando um canal privado, sem conteúdo de exploração confidencial. Use exemplos sintéticos e não publique credenciais.

O suporte se concentra na versão atual. Uma comparação considerada compatível não substitui testes de integração dos clientes nem revisão humana de uma alteração de API.
